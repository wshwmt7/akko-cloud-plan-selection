## 三网 CN2 GIA 回程，解决的是晚高峰掉速

AkkoCloud 的线路口径是去程走中国电信 CN2 GIA，回程三网（电信、联通、移动）都走 CN2 GIA。对国内用户来说，这条线路的价值集中在一个时间点：晚上八点到十一点。普通国际线路在这个时段容易掉到几百 KB/s，CN2 GIA 的差距就体现在这里。

路由会变。有测评站点记录过，移动回程在某段时间走的是 CMIN2 而不是 CN2，同属优化线路但不是宣传里那个词。对实际使用影响不大，介意的话下单前用下面的方法自己看路由。

三个机房的分工：圣何塞面向国内访问，是三地里最常用的；法兰克福和伦敦更适合需要欧洲 IP 的业务，官网标注三地都接中国电信 CN2 网络，机房为 T3+ 标准。法兰克福在订单页可选，公开资料里没有单独的配置价格表。

## 下单前先自己测一遍：45.9.10.146 怎么用

这一节比上面所有配置表都有用。别人说“低延迟”不算数，你自己的宽带连过去是什么样才算。

**测试 IP**：`45.9.10.146`
**测速文件**：`http://sjclg.akkocloud.com/1000MB.test`（1000MB）
**Looking Glass**：`http://sjclg.akkocloud.com/`

具体做法：

1. 先 `ping 45.9.10.146`，看平均延迟和丢包率。丢包比延迟更值得关注，持续丢包超过 2% 就要谨慎。
2. 白天（比如下午三点）用浏览器或 `wget` 单线程下载那个 1000MB 文件，记下速度。
3. 晚上 20:00 到 23:00 再测一次，同样单线程。
4. 比较两次结果。白天和晚高峰差距在 10% 以内，说明这条线路对你的宽带是稳的；晚高峰掉一半以上，说明你家到圣何塞这条路在高峰期拥堵，换机房或换商家都比硬扛更划算。
5. 打开 Looking Glass 看回程路由，确认是不是走 CN2。

下载速度换算：浏览器显示 10MB/s，约等于 80Mbps。这个数字和套餐标的带宽对比，能看出你这条本地宽带到底能吃到多少。

很多人买完才发现晚高峰不行，问题往往出在本地运营商到机房的这一段，不在机器本身。花十分钟测一遍，比看十篇测评管用。
